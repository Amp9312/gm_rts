# gm_rts
Game Maker RTS toy model example game just trying to wrap my head around the concept

Units:
worker,
soldier

Locations:
hq (player health bar basically, must be defended from OP units),
resource_node (metal),
farm (food),
generator (energy),

Room:
Battlefield,
Standard UI / Stats

Rules:
economy (how many resources does each unit cost? what resource can be used to heal hq?)
unit_commands (command unit to interact with location, command unit to fight),
building_construction (what upgrades to hq are needed to make soldiers? what bonuses are there for upgrading farms, generators, and resource nodes?)
